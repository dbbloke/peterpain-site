02 / Flagship work

The strongest cases, with the evidence grade attached.

These are the claims written for external use. Confirmed means a specific change record, ticket, email or file. Corroborated means more than one independent source. Nothing here rests on a meeting invite or assignment status alone.

Corroborated

Automated OS patching at estate scale

Took operating-system patching from manual, ticket-driven work to scheduled automated patching across the RHEL estate. Ran the gap analysis, built the Ansible and Chef content, and handed the operating model to BAU with runbooks. Later extended to remote-execution patching in production, with no downtime.

Confirmed

Satellite rebuilt as Terraform

Led the migration of a patching platform from CloudFormation-managed infrastructure to Terraform, including production cutover, shared host re-registration, configuration comparison and formal change approval. Production completed without incident.

Confirmed

Image-building platform, rebuilt as code

Replaced a pipeline in which component definitions existed in three places and could drift. Built a Terraform and GitHub Actions pipeline covering seven image types, made the repository the source of truth, and wrote Python tooling to compare production against code.

Confirmed

Advised against an unjustified migration

Analysed whether a broad move to an ARM-based instance family was technically and economically justified. It was not: missing image support, parallel validation paths, vendor package support and lock-in overhead. The recommendation was accepted and the programme paused.

Confirmed

Secrets moved off nodes

Designed and delivered the migration of host-distributed configuration secrets to a managed secrets store, including the retrieval helper, IAM model, access-control rationale, testing and a phased rollout. Correcting the access model was a precondition, not a follow-up.

Corroborated

Self-service database environments

Scripted provisioning of the managed database and data-warehouse estate into VPCs with controlled jump-host access, so teams could stand up and reset a working test environment on demand.

Corroborated

AI usage made measurable, then optimised

Instrumented AI usage to find where tokens and cost were actually going, reported daily from cost and usage data, and used the evidence to reduce token consumption.

Confirmed

Three internal AI enablement sessions

Presented an all-hands talk, ran a workshop on how the team should be using AI, and wrote an ideas report so the conversation became a backlog rather than ending when everyone left the room.

Systems thinking over product loyalty.

04 / AI-assisted engineering

AI is a force multiplier.

Evidence + domain expertise + AI reasoning

I use AI to retrieve, connect, analyse and challenge evidence at a speed that changes the engineering feedback loop — not as autocomplete, and not as autonomous production decision-making.

Observe→ Retrieve evidence→ Reconstruct context→ AI diagnosis→ Human verify→ Git / CI

Control principle: AI accelerates reasoning and implementation. Source tracing, human verification, change control and engineering governance stay in the loop.
